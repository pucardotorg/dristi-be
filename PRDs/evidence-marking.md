# 1. The flow

1. Select one or more documents and choose **Mark as evidence** (`DSB-20`, `EVM-04`).
2. Choose a numbering sequence (`EVM-09`, `EVM-10`).
3. Arrange the documents in the order they are to be numbered (`EVM-14`).
4. Draft and sign the order (`EVM-05`).
5. The documents get their exhibit numbers (`EVM-03`).

# 2. Marking a document

| ID | Requirement |
| --- | --- |
| `DSB-12` | A document can be **marked as evidence** if it is in one of the categories listed in [`case-file.md`](case-file.md) §1.2. |
| `EVM-26` | Mark as evidence and Mark witness (§5) are offered to holders of the **Order drafter** and **Order signer** roles ([`court-roles.md`](court-roles.md)). In the order, their order items are filled by an **Order data filler**, like any other order item ([`order-generation.md`](order-generation.md) `ROL-02`). |
| `DSB-20` | Marking is started from the **case file** ([`case-file.md`](case-file.md) `CFL-22`). |
| `EVM-04` | One or more documents can be marked at once. All the documents marked together take their numbers from one sequence. |
| `EVM-14` | When more than one document is selected, the user arranges them in the order they are to be numbered. |
| `EVM-05` | Marking is done by the **Mark as evidence** order item on an order (#28 of [`order-template-catalogue.md`](order-template-catalogue.md)). The order item lists the documents, in the order arranged, and the sequence chosen. When marking is started from the case file, the order opens with this order item already added. The documents are marked only when the order is **triggered**: signed, with its order data complete ([`order-generation.md`](order-generation.md) `CMP-04`). |
| `EVM-15` | Marking leaves each document exactly as it was filed. Nothing is signed, stamped or written on it; the exhibit number is recorded in the order and on the case record, not on the document. |
| `EVM-16` | An order that marks a document as evidence, unmarks it or changes its sequence (§4) is linked to that document automatically. |
| `EVM-06` | Documents can be marked at any stage of the case after registration. |
| `EVM-02` | Marking, unmarking and changing a sequence create no A-Diary entry of their own. The order that does it makes an entry like any other order ([`a-diary.md`](a-diary.md) `ADY-06`). |

*The document is left unaltered so that any signatures already on it remain valid (`EVM-15`).*

# 3. Numbers

| ID | Requirement |
| --- | --- |
| `EVM-03` | The **exhibit number** comes from the numbering sequence chosen at marking. It is given when the order is triggered: each document gets the next number in that sequence within the case, in the order the documents were arranged (`EVM-14`). Until then the order shows no exhibit numbers. |
| `EVM-08` | A **numbering sequence** is a running number in a set format. For example, one sequence runs A1, A2, A3 …; another runs from the case number, as [case number]-E1, [case number]-E2 …. |
| `EVM-09` | Each state configures one or more sequences (§6). Every sequence configured for the state is offered when marking. |
| `EVM-10` | A sequence's format can include the **witness number**. Such a sequence runs separately for each witness on the case who has a number, and each witness's sequence is offered when marking. For example, CW1/1, CW1/2 … and CW2/1, CW2/2 …; or CW1/A, CW1/B …, where CW1 and CW2 are the witness numbers. |
| `EVM-07` | Every exhibit number is allotted by the system from the chosen sequence. Nobody gives an exhibit number manually, the Magistrate included. |
| `EVM-11` | A number once given in a sequence is never given again in that case, even after the document is unmarked or moved to another sequence (§4). |
| `EVM-01` | A marked document has its exhibit number as well as its document number ([`view-case.md`](view-case.md) `DOC-15`), which does not change. Each screen that lists documents sets whether it shows the exhibit number, for example the Documents tab ([`view-case.md`](view-case.md) `DOC-18`) and the case file ([`case-file.md`](case-file.md) `CFL-31`). |

*The system allots every number because there is no reason to bypass a common, rule-based sequence (`EVM-07`).*

*A number is never reused because reuse leaves too much room for confusion and conflict. For example, an order lists an exhibit number, and after the order is published that number is given to a different document; read together, the two are confusing. Unmarking is allowed so that mistakes can be corrected, but the platform keeps this one boundary to keep the record clean, even where practice in the physical court differs (`EVM-11`).*

# 4. After marking

| ID | Requirement |
| --- | --- |
| `EVM-12` | Once a document is marked, two changes can be made to it, each by order through the *Unmark/renumber exhibit* order item (#29 of [`order-template-catalogue.md`](order-template-catalogue.md)): **unmark** it, or **change its sequence**. These are the only ways its exhibit number changes. |
| `EVM-13` | A document that is **unmarked** loses its exhibit number and is no longer evidence. A document whose **sequence is changed** gets the next number in the new sequence. |
| `EVM-27` | A state can choose not to offer unmarking, renumbering, or both, for exhibits and for witness numbers (`EVM-24`). Where it does, that option is not offered. Both are offered unless a state asks otherwise. |

*Marking is not made final because courts would push back: they make mistakes and need a way to correct them (`EVM-12`).*

# 5. Witness numbers

1. Select a party and choose **Mark witness** (`EVM-17`, `EVM-19`).
2. Choose a witness-number sequence (`EVM-20`).
3. Draft and sign the order (`EVM-19`).
4. The party gets their witness number (`EVM-21`).

| ID | Requirement |
| --- | --- |
| `EVM-17` | Any party on the case can be given a **witness number**. A witness who is not yet on the case is added to it first ([`view-case.md`](view-case.md) §11). |
| `EVM-18` | One party is given a witness number at a time. |
| `EVM-19` | A witness number is given by the **Mark witness** order item on an order (#30 of [`order-template-catalogue.md`](order-template-catalogue.md)). The order item names the party and the sequence chosen. It can be started from the Parties tab, which opens an order with this order item already added, or added to an order from the order items. The party gets the number only when the order is triggered. |
| `EVM-20` | A witness number comes from a **witness-number sequence**: a running number in a set format, for example CW1, CW2 …. Each state configures one or more (§6). Witness-number sequences are offered when giving a witness number. |
| `EVM-21` | When the order is triggered, the system allots the party the next number in the chosen sequence within the case. Witness numbers follow the same rules as exhibit numbers: nobody gives one manually (`EVM-07`), and a number once given is never given again in that case (`EVM-11`). |
| `EVM-22` | A party has no witness number until an order gives them one. |
| `EVM-23` | A witness's exhibit sequence (`EVM-10`) is offered only after the order giving the witness their number is triggered. Numbering a witness and marking documents under their number therefore take two orders. |
| `EVM-24` | Once a party has a witness number, two changes can be made, each by order through the *Unmark/renumber witness* order item (#31 of [`order-template-catalogue.md`](order-template-catalogue.md)): **remove** the witness number, or **change its sequence**, which gives the next number in the new sequence. Neither is allowed while a document holds an exhibit number built on that witness number. Once every such document is unmarked or moved to another sequence, both are allowed again. |

*Two orders are acceptable for now. In court the witness is examined first and the order recording it is passed; the witness's documents, such as their deposition, can be on the case file in the meantime and are marked once that order is triggered (`EVM-23`).*

# 7. Enhancements

- In a later version, the recorded-statements flow becomes the main way to give a witness number. While recording a statement, the court gives the witness their number from a sequence, and the recorded statement is marked as an exhibit under that witness number automatically. The Parties tab (`EVM-19`) stays as a second way.
- In a later version, an order item can add a *Mark as evidence* order item to its order automatically, for several documents in a set sequence. For example, a *Cognizance* order item could add one that marks all the original filing documents. This is still marking by order.
